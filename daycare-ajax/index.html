Read this first

  • CWELCC = fee cap (~$22/day max under age 6) at enrolled centres. No separate application.
  • Durham Fee Subsidy = extra income-tested help. No waitlist for subsidy itself — you need a secured space + start date within ~3 months to apply.
  • Ajax has no single regional waitlist. Join each centre separately this week.
  • Distances are approximate driving estimates from L1S 0B1. Confirm on Maps before tours.
  • Ratings are parent Google / aggregate scores where found — not Ministry rankings. Always open the review links and Ontario inspection reports yourself.

How we treated “ratings”

Ontario does not publish a single star score for daycares. Use three layers:

  • Parent reviews — Google / Maps (link on each card)
  • Ministry inspections — Ontario licensed child care search (compliance reports)
  • Durham quality — Region Operating Criteria / ask centre for recent assessment

Official inspection search: Search licensed child care (Ontario) · Durham directory: Child Care Directory
