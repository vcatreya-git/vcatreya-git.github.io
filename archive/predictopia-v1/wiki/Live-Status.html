How to run locally

cd ~/projects/predictopia
npm install
# ensure .env.local has Supabase + CricketData keys
npm run dev
# → http://localhost:3000

Deploy (Vercel)

cd ~/projects/predictopia
npx vercel login
npx vercel --prod
# set env vars in Vercel dashboard to match .env.local
# Google OAuth redirect: https://<deployment>/auth/callback
