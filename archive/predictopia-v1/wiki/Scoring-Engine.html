Scoring Engine — Predictopia

How points, streaks, achievements, and prizes are computed. Portfolio readers: this is the rules engine product surface — fair, transparent, family-safe, free-tier capable.

Companion: User Flows (result path), Data Model, Feature Map.

Base match points

Outcome Points Notes
Correct winner 2 IPL always has a winner (super over)
Incorrect 0
No result / abandoned 1 Everyone who submitted a pick
No prediction 0 Missed deadline or skipped

No draw option in the UI — matches product reality of IPL. Weighted knockout points (Eliminator 3, Qualifier 4, Final 5) are V1.1 optional polish; V1 keeps the mental model simple: 2 points per correct match.

When scoring runs

  1. Match result becomes available (CricketData fetch or admin override).
  2. System evaluates each pool member’s prediction for that match_id.
  3. Points written on predictions.points_awarded; streaks updated; achievements checked.
  4. leaderboard_cache refreshed for weekly / monthly / overall periods.

At family scale, calculation is synchronous in the request path — no job queue required. Portfolio decision: optimise for operational simplicity until scale demands workers.

Result acquisition (API thrift)

Path Behaviour
Cache hit Serve match_results — zero external calls
Cache miss Fetch CricketData once; insert with conflict ignore
Admin override Write with source = admin_override for disputes

This is product strategy, not an accident: free-tier sports APIs force architecture choices that also make the app snappy for the 2nd–Nth member.

Streaks

  • Tracked per pool (not global across pools).
  • Hot streak: consecutive correct picks in that pool.
  • Profile may surface best active streak across pools for vanity.
  • Wrong pick or miss breaks the chain; abandoned/no-result behaviour follows scoring policy (1 pt path does not invent false “wins” for streak marketing — exact streak rules live in scoring service code).

Achievements (V1)

Badge Rule (product intent) Status
Hot Streak N correct in a row (e.g. 5) V1
Perfect Week All predicted matches that week correct V1
Team Loyalist Consistent pick of one franchise when eligible V1
Upset Caller Correct underdog pick Deferred — needs odds/underdog data (V1.1+)

Prize engine

Inputs

  • Buy-in per member
  • Commission % (0–50), admin-only in UI
  • Distribution tier (Winner Takes All, Top 3, … Top 50)
  • Period (chunk / weekly / monthly / season) via league style

Prize pool

prize_pool = sum(paid_buy_ins) * (1 - commission_rate)

Unpaid members do not inflate the pot. That encodes the real family rule: “no pay, no prize share.”

Nx distribution

Position N from the bottom of the paid places gets N× share of a fixed part total.

Example Top 3: 3× + 2× + 1× = 6 parts → 1st gets 3/6, 2nd 2/6, 3rd 1/6 of prize_pool.

Ties

Tied ranks split the sum of prizes for those ranks equally.
Rank inversion guard: ensure a lower display rank never earns more than a higher one after splits — a subtle fairness bug that appears only under ties.

Offline settlement

App records who should receive what and who was marked paid.
No card rails, no UPI API — regulatory and complexity boundary for V1. Portfolio skill: choosing the right product boundary.

Live preview

At create (and as expected/paid headcount changes), admins see place amounts update live — reducing WhatsApp money arguments before season start.

Leaderboards

Timeframe Purpose
Weekly (Mon–Sun) Short-loop bragging
Monthly Mid-season narrative
Season overall Prize settlement

Leaderboards live inside Pool Home as a tab, not as global navigation — pools are the social unit.

Top 4 / Season Winner competitions

Optional one-off competitions auto-generated from league style (bragging and optional pots). Separate prediction tables (migrations 005–006). See API Reference.

Worked example (portfolio interview)

Pool of 10 paid members × ₹500 buy-in, commission 10%, Top 3:

  • Gross: ₹5,000
  • Commission: ₹500
  • Prize pool: ₹4,500
  • Parts: 6 → 1st ₹2,250 · 2nd ₹1,500 · 3rd ₹750

If 1st and 2nd tie: they split (2250+1500)/2 = ₹1,875 each; 3rd still ₹750. Guard ensures no inverted outcomes after multi-way ties.
