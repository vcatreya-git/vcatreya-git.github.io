Diagrams — Predictopia

Portfolio architecture and journey diagrams in draw.io (diagrams.net), same standard as PMRocket diagrams.

Source folder: docs/diagrams/
Tool: app.diagrams.net or VS Code Draw.io Integration (hediet.vscode-drawio)

Open any .drawio file from the table below. SVG/PNG exports (when refreshed) land in docs/diagrams/export/.
