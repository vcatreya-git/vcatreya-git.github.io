Technical highlights

RLS nuclear fix (007)

Recursive pool_members policies rewritten so no policy queries its own table. Hybrid RLS + API for time-dependent rules.

Cutoff-enforced predictions

Lock at query time via cutoff_at — no toss-detection cron. Change until deadline; last pick wins.

Commission prize engine
