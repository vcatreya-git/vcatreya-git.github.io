Feature Map

Feature phasing across V1 (family MVP), V1.1 (fast follow), and V2 (post-season growth). Every feature listed here was explicitly discussed and approved in the Decision Log.

Build status (2026-07-28): V1 feature set is implemented in code (phases 1–5). Supabase + schedule seed done. Production re-deploy and family E2E are the remaining ship steps. See Live Status.

V1 — Family MVP

The minimum product that lets a family run IPL predictions with zero manual work after pool setup.

Authentication and Identity

Feature Status Details
Google-only auth V1 Phone OTP deferred (may need paid Twilio). Google covers all family members.
Auto-populate display name + avatar V1 Pulled from Google OAuth profile. Editable later.
Pick favourite IPL team (onboarding) V1 Tints nav bar + accent colour.

Pools

Feature Status Details
Pool creation + permanent join link V1 One link, admin shares once, members pin it.
Private pools only (invite-link) V1 is_public boolean in schema from day one; discovery is V2.
Max pool size: 100 members V1 Join requests auto-rejected when full.
Multi-admin (WhatsApp model) V1 Creator / Admin / Member roles. Creator can't be removed.
Creator vs Admin permission split V1 Creator controls money + pool existence. Admins help with daily ops.
Admin screen (2 tabs) V1 Gear icon → 2 tabs: (1) Settings + Competitions, (2) Requests + Budget. No Cards tab — share buttons on Pool Home. Commission/buy-in/league style locked after first match.
Join request flow V1 Paid: request + approval. Free: auto-join. Approve != Paid.
Mid-season exit: buy-in stays V1 No refund. Points frozen. Predictions preserved for history.
Pool cards: pin/favourite, winnings V1 Pinned sort to top. Show Won only (never net loss).

Predictions

Feature Status Details
One-tap prediction (Team A or B) V1 No tie option. Duolingo-style predict/done UX.
Advance predictions (next 5 matches) V1 Changeable until cutoff. Engagement on no-match days.
Auto-lock before toss V1 Fixed ~30 min before scheduled start.
Predictions visible after cutoff only V1 Independent thinking before, banter after.
Predictions are per-pool V1 Different pools, different strategies.
Prediction share card V1 All members' picks grouped by team after cutoff.

Match Data and Results

Feature Status Details
IPL schedule preloaded V1 CricketData.org. Daily cron at 00:30 IST.
On-demand result fetch (cached) V1 First tap triggers API. One write per match via upsert.
Admin result override V1 For disputes only. Source marked as admin_override.
Times in member's local timezone V1 Stored UTC, displayed in browser locale.

Scoring and Leaderboards

Feature Status Details
Scoring: 2/0/1 (abandoned) V1 All matches worth 2 pts. No ties in IPL.
Synchronous score calculation V1 No background jobs at family scale.
Weekly/monthly/season leaderboards V1 Tab inside Pool Home, not standalone.
Streaks per-pool V1 Independent per pool. Profile shows best active streak across pools.
Visual streaks + achievements V1 Hot Streak, Perfect Week, Team Loyalist.

Prizes and Money

Feature Status Details
Commission slider (0-50%) V1 Admin sets, system computes prize pool.
Nx distribution formula V1 Position N from bottom = Nx share.
Distribution tiers V1 7 tiers from Winner Takes All to Top 50.
Live prize preview V1 Admin enters expected size, preview updates live.
Prize periods: configurable (chunks/weekly/monthly/season) V1 Admin picks league style; competitions auto-generated. Per-chunk pot set once, applied uniformly.
Competition model V1 Auto-generated from league style. One-offs: Top 4, Season Winner (default on, bragging only). No CompetitionBuilder UI — all auto-generated.
Tie-breaking with rank inversion guard V1 Split equally, guard prevents inversion.
Pool budget tracker (admin-only) V1 Total, allocated, paid, remaining, surplus.
Never show losses to members V1 "Won X so far" only. Buy-in is sunk.
Commission % is admin-only V1 Members see amounts, never the percentage.
Money stays offline V1 App tracks, doesn't process payments.

Navigation and UX

Feature Status Details
3-tab bottom nav V1 My Pools / Predict / Profile.
Max depth 2 from any tab V1 Bottom nav always visible.
Predict tab: all pools unified V1 Grouped by pool, soonest cutoff first.
Members view: one screen, role-aware V1 Admins see paid/unpaid toggle, make admin, remove.

Sharing and Growth

Feature Status Details
Screenshot cards with QR/link V1 Shareable by ALL members.
Native share sheet V1 navigator.share on mobile. Copy + download on desktop.
Feature board (submit + upvote) V1 Profile > Feature Board. Simple list.

Design and Theming

Feature Status Details
Light, bright, energetic theme V1 White backgrounds, vibrant team colours. bet365 + Daily Faceoff energy.
No copyrighted images V1 Team abbreviations in team colours.
Accessibility for seniors V1 48px min tap targets, high contrast, clear labels.

V1.1 — Fast Follow (April 5-18)

Features explicitly deferred from V1 during brainstorming.

Feature Details
Phone OTP auth For family members without Google accounts. May need Twilio.
Configurable match point values Default 2 for league. Admin sets higher for knockouts (Eliminator 3, Qualifier 4, Final 5).
Top 2/3/5 prize splits with custom % Full prize configuration UI beyond winner-takes-all per tier.
Full team palette theming V1 stores selection, applies nav + accent. V1.1: full 10-palette override.
"My Money" cross-pool view Total invested, total won, net, pending payouts, per-pool breakdown.
Illustrated/caricature player cards Visual upgrade from abbreviations. Avoids likeness rights.
Public pools + search/browse is_public already in schema. Discovery when enough pools exist.
Prorated points for mid-season joiners Admin toggle. Average of all members' scores per missed match.
Automated WhatsApp/Telegram notifications V1 admin shares links manually. V1.1 adds automated reminders.
Knockout-specific prize pots Qualifier, Eliminator, Final each get own pot and tier.

V2 — Growth (Post-IPL 2026)

Larger features requiring architecture changes or meaningful user base.

Feature Details
Multi-league support EPL, NBA, F1, MotoGP. Schema supports any sport from day one.
Automated notification channels Email, SMS, WhatsApp Business API, Telegram bots.
Ads integration Primary monetisation. Ad-supported, never charge users.
Configurable bonus points Data tracked from V1, scoring toggles exposed in V2.
Custom scoring rules per group Beyond 2/1/0 default. Admin-defined schemes.
White-label for brands Predictopia as a platform other brands can skin.
Cross-pool aggregate stats Profile-level stats across all pools.
Public pool discovery Search/browse public pools.
Advanced analytics Prediction accuracy trends, team bias analysis, head-to-head records.
