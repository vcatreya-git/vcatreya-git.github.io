Product Overview

What Predictopia does

Predictopia is a mobile-first web app where anyone creates a prediction pool, shares a single permanent link, and the app runs the entire league automatically. No daily Google Sheets, no WhatsApp message chaos, no manual score tallying. The admin's job after initial setup: nothing.

The app handles schedule imports from CricketData.org, prediction collection with auto-lock before toss, result fetching, scoring, leaderboards, and prize tracking. Members make one-tap predictions (Team A or Team B) and see everyone's picks revealed after cutoff. Leaderboards, streaks, and achievement badges keep the competitive energy alive across a 70+ match IPL season.

Who it's for

Primary persona: Pool Admin

The person who voluntarily takes on the work of running a prediction league. They spend 15-30 minutes per match day on admin tasks using Google Sheets. Over 70+ IPL matches, that's 17-35 hours of unpaid work per season. Predictopia reduces this to zero after initial pool setup. If the admin's pain is eliminated, the pool survives the full season. The admin is also the distribution channel -- they create pools and invite members.

Design for the family

Accessibility matters: large tap targets (48px minimum), big readable text, high contrast, one primary action per screen, clear labels ("Pick your winner" not "Submit prediction"). Simple enough for non-tech-savvy seniors.

The pool model

Pool creation

Any authenticated user can create a pool. They set a name, icon, buy-in amount (or free at INR 0), commission percentage, and prize distribution tier. The system generates a permanent join link -- one link, shared once, pinnable in WhatsApp.

Joining a pool

  • Free pools (INR 0 buy-in): Tap the link, auto-join instantly.
  • Paid pools: Tap the link, see buy-in amount upfront, request to join. Admin approves the request. Admin separately marks "Paid" when money arrives offline. Approve and Paid are two separate states because UPI and cash payments are asynchronous.

Roles (WhatsApp model)

Role Can do
Creator Everything. Change buy-in/commission/prizes, delete pool, remove admins. Cannot be removed.
Admin Approve joins, mark paid, screenshot cards, override results, remove members.
Member Predict, view leaderboard, view prizes, share cards.

Pool limits

Max 100 members per pool. Predictions are per-pool -- a member in three pools can predict differently in each. Mid-season exit: buy-in stays in the pool (no refund), predictions preserved, points frozen.

Scoring

Base scoring

Outcome Points
Correct prediction 2
Wrong prediction 0
Match abandoned / no result (rain) 1 (everyone)

In V1, all matches are worth 2 points. Admin-configurable point values for knockouts (Eliminator 3, Qualifier 4, Final 5) are V1.1.

Leaderboards

Three timeframes: weekly (Mon-Sun), monthly (calendar month), and season overall. Leaderboards live inside Pool Home as a tab, not as standalone navigation. Updated synchronously after each match result -- no background jobs needed at family scale.

Streaks and achievements

Streaks are tracked per-pool. A streak in Pool A and Pool B are independent. Profile shows best active streak across pools.

Achievement Criteria
Hot Streak N consecutive correct predictions
Perfect Week 100% accuracy for a Mon-Sun week
Team Loyalist Always predicts the same team
Upset Caller Correctly predicted an upset (V1.1 -- no underdog data source in V1)

Prizes

How prize calculation works

  1. Admin sets commission (0-50% slider). Commission is admin-only -- members never see the percentage.
  2. System computes prize pool = total buy-ins x (1 - commission / 100).
  3. Admin picks distribution tier: Winner Takes All, Top 3, Top 5, Top 10, Top 20, Top 25, or Top 50.
  4. Nx multiplier formula: Position N from bottom gets Nx share. For Top 3: 3x + 2x + 1x = 6 total parts.
  5. Live preview shows exact amounts per rank. Admin enters expected pool size during creation; preview updates as members actually join and pay.

Tie-breaking

If N people tie at rank R, they split the sum of prizes for ranks R through R+N-1, divided equally. A rank inversion guard ensures tied people always get at least as much as the rank directly below them.

Prize periods

V1 supports three periods: weekly (12 weeks in league stage), monthly (3 months), and season overall. Admin sets pot size and tier for each. Knockout-specific prize pots (qualifier, eliminator, final) are V1.1.

What members see vs what admins see

Members Admins
Prize amounts Yes Yes
Who won Yes Yes
Paid / unpaid Yes Yes
Commission % No Yes
Pool balance No Yes
Allocated budget No Yes
Admin surplus No Yes
Net loss No Yes (budget tracker)

Members see "Won INR 100 so far" -- never "Net -INR 400." Buy-in is treated as a sunk entry fee, not an investment. Showing losses discourages participation.

Money stays offline

The app tracks prizes but does not process payments. Payouts are marked in-app by the admin when money is transferred via UPI, cash, or other offline means.

Match data pipeline

Schedule

IPL 2026 schedule is preloaded from CricketData.org. A daily Vercel Cron at 00:30 IST refreshes the schedule to catch time changes or newly announced matches. One API call per day.

Results

Results are not polled. The first user who opens a completed match card triggers an on-demand API call to CricketData.org. The result is cached via database upsert (ON CONFLICT DO NOTHING -- first write wins). Subsequent users read from cache. Total API usage: approximately 1 call per match across the entire user base.

Cutoff

Predictions lock at a fixed time ~30 minutes before scheduled match start. Not tied to actual toss detection. Server time is authoritative -- frontend shows a countdown, but enforcement is server-side.

Sharing

What can be shared

  • All members: Leaderboard position, their predictions, achievements, match results
  • Admins additionally: Payout cards, "who hasn't predicted" nudge cards, budget summary

How sharing works

Mobile: one tap triggers navigator.share() for the native device share sheet (WhatsApp, Telegram, etc.) with pre-filled text + pool link. Desktop: copy link + download as image.

Every screenshot card embeds a QR code and pool join link. Every share is organic marketing -- the card is the invite.
