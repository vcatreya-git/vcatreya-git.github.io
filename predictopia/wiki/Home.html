Predictopia

Multi-group sports prediction leagues that run themselves — schedule, picks, scoring, leaderboards, and prizes. Built for IPL 2026 family use; architected for any sport or league.

What is Predictopia?

Running a prediction league by hand is a seasonal tax: Google Sheets, coloured cells, WhatsApp chaos, and manual score tallying across 70+ matches. Predictopia removes that work after pool setup.

  1. Create a pool — name, buy-in (or free), commission, prize tiers
  2. Share one permanent join link — pin it in WhatsApp once
  3. One-tap predictions — Team A or Team B before cutoff
  4. Auto lock & reveal — after cutoff, everyone’s picks are visible
  5. Scoring & leaderboards — weekly / monthly / season
  6. Prize tracking — money stays offline (UPI/cash); app tracks who paid and who won

As a portfolio project, Predictopia demonstrates:

Lived-problem product craft — designed from real family league ops, not abstract market research.

Access control under pressure — hybrid RLS + API enforcement after a recursive RLS failure and nuclear rewrite (migration 007).

Event-driven prediction rules — cutoff enforced at query time; no toss-detection cron for locks.

Commission-based prize engine — Nx distribution, live preview, rank-inversion guard for ties.

API thrift — CricketData schedule via daily cron; results on-demand with first-write-wins cache.

What makes it technically interesting

RLS nuclear fix (migration 007)

Early pool_members policies queried pool_members to prove membership → infinite recursion. Migration 007 drops all policies on 15 tables and rebuilds with: never self-query the same table in a policy; membership uses auth.uid() = user_id or pools.created_by; fine-grained rules live in API routes where time and role logic are clearer.

Cutoff-enforced prediction engine

Cutoff is ~30 minutes before scheduled start (stored as cutoff_at). Enforcement is now() < cutoff_at in API routes — no background job. Before cutoff: only own pick visible. After: pool-wide reveal (Realtime-friendly). Upserts allow change-until-lock; last pick wins.

Commission prize engine

Admin sets buy-in and commission 0–50%. Prize pool = total buy-ins − commission. Distribution tiers (Winner Takes All → Top 50) use Nx shares from the bottom of the paid rank. Ties split pot shares with a guard so rank inversion cannot pay 2nd more than tied 1st.

CricketData.org integration

  • Schedule: Vercel Cron daily → /api/cron/refresh-schedule upsert
  • Results: first user to open a completed match triggers fetch; ON CONFLICT DO NOTHING → one API call per match

Multi-pool predictions

Predictions are scoped (pool_id, user_id, match_id). One person can run different strategies in different family groups.

Join request + paid states

Paid pools: request → admin approve → admin marks Paid separately (async UPI/cash). Free pools: auto-join.

Screenshot-native sharing

navigator.share on mobile; clipboard + image fallback on desktop. Cards for leaderboard / picks / unpaid nudges include join QR for viral distribution.
