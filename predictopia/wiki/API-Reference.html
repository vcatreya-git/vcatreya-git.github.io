API Reference

All endpoints are Next.js API Routes (/api/*). Auth is handled via Supabase Auth JWTs passed as Bearer tokens. Unless marked "optional", all endpoints require authentication.

Authentication

Auth is handled entirely by Supabase Auth. No custom auth endpoints. The frontend uses @supabase/auth-helpers-nextjs.

  • Provider: Google OAuth (V1). Phone OTP deferred to V1.1.
  • Session: JWT issued by Supabase, verified server-side via supabase.auth.getUser().

User Profile

Create or update profile

POST /api/users/profile
Auth: required

Request:

{
  "display_name": "Venkat",
  "avatar_url": "https://...",
  "favourite_team": "CSK"
}

Response:

{
  "id": "uuid",
  "display_name": "Venkat",
  "avatar_url": "https://...",
  "google_avatar_url": "https://lh3.googleusercontent.com/...",
  "favourite_team": "CSK"
}

On first creation, display_name and google_avatar_url are auto-populated from the Google OAuth profile.

  "buy_in_amount": 500,
  "max_members": 100,
  "commission_pct": 20,
  "distribution_tier": "top3",
  "late_join_policy": "zero"

Response:

{
  "id": "uuid",
  "name": "Family IPL 2026",
  "join_code": "abc123",
  "join_url": "/join/abc123",

  "commission_pct": 20,
  "distribution_tier": "top3",

Side effects: Creates pool_members row (role: creator, status: active) and pool_budget row.

Auth: optional

Response:

  "pool_id": "uuid",
  "name": "Family IPL 2026",
  "icon_url": "https://...",
  "member_count": 15,
  "is_member": false
}

Public endpoint. Shows pool preview without revealing internals.

Join pool

POST /api/pools/{pool_id}/join
Auth: required

Response:

{
  "pool_member": {
    "id": "uuid",
    "pool_id": "uuid",
    "user_id": "uuid",
    "role": "member",
    "status": "active",
    "payment_status": "unpaid",
    "joined_at": "2026-03-29T10:00:00Z"
  }
}
  • Free pools (buy_in = 0): status set to active (auto-join).
  • Paid pools (buy_in > 0): status set to pending (requires admin approval).
  • Errors: 403 if blocked, 409 if already member, 422 if pool full (max_members reached).

Pool Admin

Update member role

PUT /api/pools/{pool_id}/members/{user_id}/role
Auth: required (creator or admin)

Request:

{ "role": "admin" }

Error: 403 if targeting the creator.

Remove member

DELETE /api/pools/{pool_id}/members/{user_id}
Auth: required (creator or admin)

Sets pool_members.status = 'removed' and removed_at = now(). Historical predictions preserved for leaderboard integrity.

Error: 403 if targeting creator, or if a non-admin calls it.

Block member

PUT /api/pools/{pool_id}/members/{user_id}/block
Auth: required (creator or admin)

Sets status = 'blocked'. Blocked members cannot rejoin via the same link.

Update payment status

PUT /api/pools/{pool_id}/members/{user_id}/payment-status
Auth: required (creator or admin)

Request:

{ "payment_status": "paid" }

Separate from approval. Approve = "you're in." Paid = "I got your money."

Matches

List matches

GET /api/matches?status=upcoming&limit=10
Auth: required

Response:

{
  "matches": [
    {
      "id": "uuid",
      "team_a": "CSK",
      "team_b": "MI",
      "team_a_name": "Chennai Super Kings",
      "team_b_name": "Mumbai Indians",
      "match_number": 1,
      "match_type": "league",
      "venue": "M.A. Chidambaram Stadium",
      "scheduled_at": "2026-03-28T14:00:00Z",
      "cutoff_at": "2026-03-28T13:30:00Z",
      "status": "upcoming"
    }
  ]
}

Get match result (on-demand fetch)

GET /api/matches/{match_id}/result
Auth: required

Response:

{
  "result": {
    "winner": "CSK",
    "result_type": "normal",
    "result_summary": "CSK won by 6 wickets",
    "source": "api"
  },
  "match_status": "completed"
}

Side effects: If no cached result and the match appears completed, triggers an external API call to CricketData.org, caches the result via upsert, and cascades score calculation for all pools.

Admin result override

POST /api/admin/matches/{match_id}/result
Auth: required (must be admin/creator of at least one pool)

Request:

{
  "winner": "CSK",
  "result_type": "normal",
  "result_summary": "CSK won by 6 wickets"
}

Writes/overwrites match_results with source = 'admin_override'. Re-triggers scoring for all pools.

Predictions

Submit prediction

POST /api/predictions
Auth: required

Request:

{
  "pool_id": "uuid",
  "match_id": "uuid",
  "predicted_team": "CSK"
}

Response:

{
  "prediction": {
    "id": "uuid",
    "pool_id": "uuid",
    "match_id": "uuid",
    "predicted_team": "CSK",
    "created_at": "2026-03-28T12:00:00Z"
  }
}

Uses INSERT ... ON CONFLICT (pool_id, user_id, match_id) DO UPDATE SET predicted_team, updated_at.

Errors: 403 if after cutoff, 403 if not a pool member, 404 if match not found.

Get predictions for a match

GET /api/predictions/{pool_id}/{match_id}
Auth: required (must be pool member)

Before cutoff:

{
  "my_prediction": { "predicted_team": "CSK" },
  "total_predicted": 8,
  "total_members": 15
}

After cutoff:

{
  "predictions": [
    {
      "user_id": "uuid",
      "display_name": "Venkat",
      "avatar_url": "https://...",
      "predicted_team": "CSK",
      "points_awarded": 2
    }
  ],
  "my_prediction": { "predicted_team": "CSK" }
}

Before cutoff, only returns own prediction + aggregate count. After cutoff, returns all members' predictions.

Get upcoming predictions

GET /api/predictions/{pool_id}/upcoming
Auth: required (must be pool member)

Response:

{
  "matches": [
    {
      "match_id": "uuid",
      "team_a": "CSK",
      "team_b": "MI",
      "scheduled_at": "2026-03-29T14:00:00Z",
      "cutoff_at": "2026-03-29T13:30:00Z",
      "my_prediction": "CSK"
    }
  ]
}

Returns next 5 upcoming matches with the user's prediction status.

Prizes

Get pool prizes (member view)

GET /api/prizes/{pool_id}
Auth: required (must be pool member)

Response:

{
  "prizes": [
    {
      "timeframe": "weekly",
      "period_key": "2026-W14",
      "amount": 200,
      "winner_display_name": "Venkat",
      "paid": true
    }
  ]
}

Members see winner + amount + paid status only. No pool economics.

Configure prize (admin)

POST /api/admin/prizes/{pool_id}
Auth: required (creator or admin)

Request:

{
  "timeframe": "weekly",
  "period_key": "2026-W14",
  "amount": 200
}

Mark prize paid (admin)

PUT /api/admin/prizes/{prize_id}/paid
Auth: required (creator or admin)

Side effects: Updates pool_budget.total_paid.

Get budget (admin only)

GET /api/admin/budget/{pool_id}
Auth: required (creator or admin)

Response:

{
  "total_collected": 7500,
  "total_allocated": 6000,
  "total_paid": 2400,
  "remaining": 3600,
  "surplus": 1500
}

Never exposed to members.

Screenshot Cards

Generate leaderboard card

GET /api/cards/leaderboard/{pool_id}?timeframe=overall
Auth: required (pool member)

Response: PNG image (server-rendered via @vercel/og / satori).

Includes pool name, top 5 rankings, QR code with join link. Optimized for WhatsApp image sharing.

Cron

Refresh schedule

GET /api/cron/refresh-schedule
Auth: Vercel Cron (verified via CRON_SECRET header)

Called daily at 00:30 IST. Fetches IPL 2026 schedule from CricketData.org and upserts into matches table.
