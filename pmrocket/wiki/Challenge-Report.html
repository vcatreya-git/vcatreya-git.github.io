Previous phase reviews (historical context)

V2a Pre-Build Review (2026-03-25)

Solution-agent challenge pass: PROCEED WITH MITIGATIONS.

0 blockers. 6 risks. 9 observations.

Key pre-build decisions:
- gap_pct: artefact-level (not skill-level). 1 - (evidenced / total_artefacts) × 100. Deterministic and LLM-independent.
- Navigator: V2a.1 (not V2a). Q16 ships in V2a for data collection; Q17–Q19 logic deferred to reduce scope.
- Minimum Viable Corpus: 4 slices, 80 JDs. Gap analysis hidden for unseeded slices (honest placeholder).

Mitigated risks:
| Risk | Mitigation |
|---|---|
| JD corpus cold-start | Scoped to 4 slices. Sourcing in parallel with build. |
| Skill name fragmentation (LLM outputs non-vocabulary skills) | Extraction constrained to existing skill_frequency.skill_name list. Admin normalises during preview. |
| Weighted matching is editorial guessing | Alpha is calibration phase. Archetype distribution monitored. Weights admin-editable at runtime. |
| Navigator scope creep (demand unknown) | Deferred to V2a.1. Q16 collects data; if >20% say Yes, accelerate. |
| ETL extraction inconsistency | Vocabulary constraint + admin review gates each extraction. |
| Multi-select intake breaks schema | Reverted to single-select. Multi-select (Q15 activities) stays for flexibility. |

Observations:
- Radar chart (V1) traded for gap_pct (V2a+). Visual richness for accuracy. Monitor user feedback.
- pgvector HNSW performant at <1K JDs (Alpha–V2a scale). Revisit query patterns at 10K+ corpus.
- 8–10 week solo build timeline mitigated by: 4-slice MVC, Navigator deferral, parallel content seeding.
