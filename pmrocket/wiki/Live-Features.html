Live Features — Phase 7d

This page documents what is currently live and working in PMRocket, deployed on Vercel. Everything below is running on the free tier (Vercel, Neon, Clerk, Groq).

Pages and Navigation

AppNav (Global)

Appears at the top of every page:
- PMRocket logo (left)
- Personalized greeting: "Hi, {firstName} 👋" (center)
- Three-dot UserMenu (right)

The UserMenu is a reusable component with:
- Display email
- "Retake assessment" link
- "Sign out" button
- extraItems prop for page-specific additions

Clicking the greeting opens a Profile modal (see Profile page below).

BottomNav (Mobile-first)

Four-tab navigation bar at bottom of screen:
1. Home → /dashboard
2. Roadmap → /roadmap
3. Readiness → /readiness
4. Apply → /apply (locked with icon; clicks show paywall teaser)

On desktop, these tabs are available via sidebar or top navigation (Tailwind responsive classes).

Dashboard Page (/dashboard)

The home page after login. Shows:

Stats Grid
- Readiness score (large number, category breakdown link)
- Evidence logged count
- Archetype match confidence

Archetype Panel
- Current matched archetype + confidence
- Collapsible accordion showing all 8 archetypes
- "Switch to {archetype}" button on each archetype card
- Click to expand/collapse

Score Breakdown
- Grid of clickable cards: Technical | Business | Portfolio | Domain | Product
- Each card shows current points / max points
- Click any card → navigates to Roadmap filtered to that category

Gamification Strip
- Streak: "5 days in a row" (resets after 24h gap)
- Weekly: "Logged 3 artefacts this week"
- Milestone: "Reached 50% readiness"

Coming Soon Grid
- Teaser cards for V2a+ features (disabled, locked)
- "AI Gap Narrative" (V2a teaser)
- "Ready-to-Apply Gate" (V2a teaser)

Roadmap Page (/roadmap)

The evidence-logging interface. Organized by category.

Browser-Tab Layer Navigation
- Tabs: Technical | Business | Portfolio | Domain | Product
- Each tab shows all artefacts in that category

Artefact Cards (Grid, scrollable)
- Title (e.g., "Write 10 SQL Queries")
- Brief description (50 chars)
- Layer badges: "Universal" | "Archetype-specific" | "Domain/Geography"
- Evidence status indicator:
- Empty circle: not started
- Partial: Learning logged
- Filled circle: Practised or Mastered
- "Log evidence" button → opens EvidenceLogModal

EvidenceLogModal (Reusable popup)

When opened:
1. Displays artefact title + description
2. Shows key_topics[] split into three auto-calculated tiers:
- Learning (topics 0–4 of 15)
- Practised (topics 5–9 of 15)
- Mastered (topics 10–14 of 15)
3. Progressive tier checkboxes:
- Learning checkboxes always visible
- Practised tier unlocks after 5/5 Learning checked
- Mastered tier unlocks after 5/5 Practised checked
4. "Search to learn" keyword chips (from search_keywords[]) — clickable, opens Google search in new tab
5. Optional description field (200 chars, placeholder: "e.g., I wrote 10 queries against Postgres...")
6. Optional link field (auto-prefixed with https:// if user omits scheme)
7. Save button:
- Validates at least Learning tier started
- Calls POST /api/evidence-log
- Awaits readiness score recomputation
- Closes modal, shows tier unlock celebration animation
- Dashboard stats update in real-time

Score Breakdown Sidebar
- Shows current readiness breakdown by category
- Totals at bottom: "You're 62% ready"

Intake Flow (Onboarding)

New users see a multi-step questionnaire:

Step 1–11: Single-select questions
- Background, experience, skills, domain, goals
- Questions load based on previous responses (some branching in design; currently linear for Alpha)
- Users can go back/edit previous answers
- Progress bar at top

Step 12–14: Skill grids
- Q12: Technical skills (rate 1–5)
- Q13: Product skills (rate 1–5)
- Q14: Business skills (rate 1–5)
- Slider UX; displays selected value

Step 15: Activity checklist
- Multi-select: which of these have you done?
- (Build an app, Write specs, Conduct interviews, etc.)
- Users can select multiple

Complete
- Saves all responses to intake_responses table
- Calls POST /api/compute-match with all responses
- Computes weighted archetype scores
- Saves match result to archetype_matches table
- Redirects to Match Result page

Authentication

Sign up / Sign in
- Clerk-hosted auth UI
- Email + password OR Google OAuth
- Redirects to /dashboard on success
- Lazy provisioning: if Clerk webhook delays, first API call triggers DB row creation

Session validation
- All routes call auth() from @clerk/nextjs/server
- Invalid/expired session → 401 immediately
- Every user-scoped query includes WHERE user_id = $userId

Admin Pages (Auth: publicMetadata.role = 'admin')

Admin Dashboard (/admin)
- JD ingestion queue
- Curriculum Signals panel (Trending/Stable/Declining)
- Weight editor (question × archetype matrix)
- User analytics (v2a+)

JD Ingestion Queue (/admin/jd-ingestion)
1. Paste raw JD text in textarea
2. Click "Extract skills" → calls POST /api/extract-skills
3. LLM processes and returns extracted skills
4. Admin review UI:
- Each skill shows: extracted term + suggested taxonomy match
- Accept / Reject / Edit dropdown for each
5. Click "Approve batch" → calls POST /api/confirm-extraction
6. System embeds JD, writes jd_embeddings, updates skill_frequency

Weight Editor (/admin/weights)
- Table: Questions (rows) × Archetypes (columns)
- Each cell is editable (numeric weight)
- Changes take effect immediately (no deploy needed)
- Weights used in next POST /api/compute-match call

Curriculum Signals (/admin/signals)
- Three tabs: Trending | Stable | Declining
- Trending: skills in JDs but not yet in curriculum (recommend adding)
- Stable: skills already in curriculum, frequency consistent
- Declining: skills frequency dropping (recommend retiring)

Paywall and Subscription

Free tier gates:
- Intake + match result (free)
- Teaser of roadmap (see title + description, not logging)

Paid tier requires:
- Full roadmap access + evidence logging
- Gap analysis (once corpus ready)
- Readiness score tracking

Subscription flow:
1. Click "Upgrade" or try to log evidence without subscription
2. Redirects to Stripe checkout (test mode, no real charges in Alpha)
3. On success, Stripe webhook creates subscriptions row
4. User immediately gains access
5. Profile page shows "Pro" badge

Billing portal:
- "Manage subscription" link in Profile
- Redirects to Stripe customer portal
- Users can upgrade/downgrade/cancel

No email reminders Transactional email only (welcome); nudges deferred V2b
No peer evidence review UX designed; functionality deferred V2b
Navigator path (Q16–Q19) Intake questions specified; logic deferred V2a.1
Live Stripe charges Test mode only; charges deferred until traction Traction signal
