2. Progressive Artefact Tier Unlocking with Key Topics

What: Evidence logging now uses key_topics[] auto-splitting for tier progression

Details:
- Every artefact has 15 key_topics (5 per tier: Learning/Practised/Mastered)
- Evidence modal auto-splits topics into three equal tiers
- User checks boxes as they cover topics
- Completing all Learning checkboxes auto-unlocks Practised
- No manual progression logic — 100% topic-driven

Data model:
- artefacts.key_topics: TEXT[] with exactly 15 items
- evidence_log.topic_progress: JSONB { "0": true, "2": false, ... } tracking checked topics
- Tier determined by completion percentage (Learning: 0–33%, Practised: 34–66%, Mastered: 67–100%)

Impact: Makes evidence logging more granular (users see individual topics), more engaging (visible progress within each tier), and defensible (can explain exactly which topics they've covered).

3. Readiness Score Computation with Self-Healing

What: Deterministic, self-healing readiness scoring pipeline

Pipeline:
- User logs evidence → POST /api/evidence-log
- Route awaits computeAndSaveScore(userId) synchronously (no fire-and-forget)
- Score recomputed: total = Σ(artefact_maxpoints × tier_multiplier) per category
- Result UPSERTed into readiness_scores table
- Dashboard and Readiness page show real-time score update

Self-healing:
- GET /api/readiness checks for existing score row
- If missing (webhook delay, job failure), computes on-demand
- Users never see "no score available" or stale data

Tier multipliers:
- Learning: 0.5× (basic familiarity)
- Practised: 0.8× (applied experience)
- Mastered: 1.0× (interview-ready)

Impact: Score is always fresh, always available, and always correct. No stale state, no late-binding computation, no hidden failures.

Performance & Scale

Current: ~50 artefacts, 15 JDs (placeholder), <100 users

Limitations at current scale: None observed

Estimated scale before optimization needed:
- Score computation: 1000 users × 15 artefacts = <100ms per compute (sync acceptable)
- Readiness query with self-heal: <50ms (DB index on user_id)
- Roadmap artefact query (3-pass): ~30ms (indexed by layer + archetype + geography)
- RAG retrieval (K=25 on 1000 JDs): ~20ms (HNSW index)

Scale handoff to V2a+: Async score computation via AWS Batch + EventBridge when bulk updates needed.
