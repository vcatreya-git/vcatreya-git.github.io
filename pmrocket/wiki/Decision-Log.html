Decision Log — PMRocket

Key product decisions that shaped the strategy, scope, and sequencing. These are the choices that best demonstrate product thinking: problem framing, trade-off reasoning, and scope discipline.

Key decisions

Date Decision Reasoning Made By
2026-07-18 Primary market: North America first, India second Builder uses the product personally in North America. India remains a core market for product design, corpus, and portfolio narrative — but North America seeds first. Supersedes India-only primary framing in earlier documents. Venkat
2026-07-18 Build strategy: thin vertical slice on free stack before full V2a surface One geography × domain × archetype slice runnable end-to-end is more valuable than partial V2a features across many slices. Full V2a docs remain design targets, not the next sprint backlog. Venkat
2026-07-18 Stripe / live paywall deferred for Alpha Invite-only or flag-gated access is sufficient for personal use and portfolio demo. Paywall boundary is fully designed and present in the product; live charges are deferred until real traction. Venkat
2026-07-18 Production-grade SaaS craft; free-tier runtime until traction Portfolio goal is to demonstrate PM-level product thinking and production build quality — not a toy demo. Free tiers govern cost and runtime only. Auth, ownership, migrations, paywall design, admin ops, and honest metrics are always present. Venkat
2026-03-24 Paywall boundary: match result free, roadmap + gap analysis paid Free: intake + archetype match + teaser ("you have X artefacts, Y gaps — locked"). Paid: full evidence roadmap, gap analysis, evidence log, readiness signal. Match result alone is useless without the roadmap — the gap creates genuine pull toward paid. Venkat
2026-03-24 Navigator (existing PM path) deferred to V2a.1 Q16 ("Are you currently a PM?") ships in V2a for data collection only. Q17–Q19, level-filtered JDs, and goal-adjusted weights ship in V2a.1. Reduces 5+ conditional code paths from the V2a critical path. Accelerate if >20% of V2a users answer Q16 = Yes. Venkat
2026-03-24 Minimum Viable Corpus: 4 slices, 80 JDs at Alpha Technical PM + Enterprise PM × Fintech + B2B SaaS × India = 4 slices × 20 JDs. Gap analysis is hidden for unseeded slices with an honest placeholder. Expand to Growth PM and Consumer domain post-Alpha. Venkat
2026-03-24 ETL vocabulary constraint LLM extraction prompt includes the existing skill_frequency.skill_name vocabulary list. Prevents skill name fragmentation in frequency counts. New skills surface as outliers for admin review rather than auto-creating new taxonomy entries. Venkat
2026-03-25 Admin is a decision queue, not a workbench Admin interface surfaces system recommendations; admin accepts or rejects. No manual weight research, no direct JD paste workflow. Every admin screen shows a recommendation with Accept/Reject. The system originates the analysis; the admin governs it. Venkat
2026-03-22 Product territory: navigation layer, not content PMRocket must own background-to-role matching + personalised roadmap + readiness signal. Building another content or curriculum platform enters saturated territory with no differentiation. discovery-agent
2026-03-23 Business model: B2C-first Pain is individual, not institutional. Existing candidates already pay individually for prep products. B2B institutional buyer (MBA programs, bootcamps) has misaligned incentive metrics. B2B is Phase 2. hypothesis-agent
2026-07-19 Feature sequencing: Intelligence → Apply → Practice → Channels Evidence is source of truth. ETL + RAG gap must exist before job packaging (Apply). Interview practice only makes sense after resume is packaged. Coaching channels last. This defends against feature creep. Venkat
2026-07-19 Free tier vs paid boundary deferred All features free until traction justifies monetisation. Paywall is designed but not enforced. Historic candidate: match free, roadmap+gap paid. Actual enforcement waits for product-market fit signal. Venkat
2026-07-18 Production-grade SaaS craft; free-tier runtime until traction Portfolio goal is SaaS craft at scale (problem framing, persona design, scope discipline), not toy shortcuts. Free tiers govern cost only. Auth, ownership, migrations, paywall design, and honest metrics are always present. Venkat
