Wayfinder is built using the feature-agent pattern — parallel subagents per independent feature — not a solo-sequential build. Once the foundation (Supabase schema, auth, shared types) is in place in week 1, all independent features can be developed in parallel and integrated in a dedicated final week. v1 is scoped to the minimum functional system that can complete the full hero flow and sustain the evidence-logging return loop — the only scope that makes the North Star metric measurable at all. External dependencies are sequenced last: Stripe ships at the tail of v1 after all core surfaces are stable, and OpenAI is a v3 dependency only.

External dependencies
Supabase — managed service, no external approval. Start here.
Stripe — no external gate. Integration straightforward. Sequence after core flow is stable.
Resend — minimal integration. Set up when auth is complete.
PostHog — set up per-screen as screens are built. Not bolted on at the end.
OpenAI API — v3 only. Not a v1 or v2 dependency.

Open Questions

1. Pricing model final decision
Freemium vs paid-upfront is deferred to Alpha WTP interviews (5–8 interviews + landing page price test at ₹999/₹1,999/₹2,999). Stripe must support both models. This decision gates Beta pricing, not Alpha — Alpha is free access for all users regardless of model.
2. Admin surface implementation
Retool vs custom Next.js admin route. Retool is faster to build; custom admin route keeps the tech stack simpler. Decision belongs in the architecture phase.
3. Archetype Explorer UX guard
The Explorer (now in v1) lets users browse all 4 archetypes and switch their target. Design must ensure it does not create a shortcut path that bypasses the structured intake — the intake match should remain the primary activation path. Needs UX design thinking before v1 feature dev begins.
4. AI PM content expertise
AI PM is a first-class v1 archetype. The evidence-building curriculum (eval set design, model lifecycle documentation) requires domain-expert input. Source this before v1 content is seeded.
5. Score credibility calibration
Does the 75/100 Apply threshold hold in Alpha? This is the most critical number to validate early. Admin tooling to change it without code deployment is already in scope — instrument it from day one.
